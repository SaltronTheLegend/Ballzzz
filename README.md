# 🟠 Ballzzz – Physics-Based Arcade Game (Unity)

A physics-driven arcade game inspired by the popular “Ballz” mobile game, built using Unity with a focus on gameplay mechanics, collision systems, and shader-based rendering.

---

## 🚀 Overview

Ballzzz is a recreation of a classic arcade gameplay loop where the player launches balls to break blocks using physics-based interactions.

This project emphasizes:
- Real-time physics simulation
- Collision-driven gameplay
- Shader-based rendering for visual effects

---

## 🛠️ Tech Stack

- Unity Engine
- C#
- ShaderLab
- HLSL (GPU programming)

---

## 🎯 Features

- Physics-based ball movement using Unity Rigidbody
- Collision detection and response system
- Multi-hit block destruction mechanics
- Trajectory-based gameplay (angle + bounce logic)
- Custom shaders for rendering and visual effects
- Frame-based gameplay loop

---

## 🎮 Gameplay Mechanics

- Player launches multiple balls at an angle
- Balls bounce off surfaces and hit blocks
- Each block requires multiple hits to break
- Efficient trajectory planning is key to clearing levels

---

## 🧠 Key Learnings

- Implemented physics-driven gameplay using Unity’s Rigidbody system
- Designed collision handling for dynamic interactions
- Explored GPU-based rendering using ShaderLab and HLSL
- Managed object lifecycle using Unity’s MonoBehaviour system
- Structured gameplay logic for scalability and reuse

---

## ⚙️ Project Structure

- `Assets/Scripts/` → Core gameplay logic (C#)
- `Assets/Shaders/` → Custom shaders (ShaderLab / HLSL)
- `Assets/Scenes/` → Game scenes
- `ProjectSettings/` → Unity configuration
